# SafeNet Junior

Platformă web educațională interactivă destinată dezvoltării competențelor de siguranță digitală pentru elevii claselor I–IV.

Proiect realizat în cadrul concursului **Tekwill Junior Ambassadors**, categoria **Proiectare și Dezvoltare Web**.

---

## 1. Descriere generală

SafeNet Junior este o aplicație web dezvoltată utilizând HTML, SCSS, Tailwind CSS și JavaScript (vanilla), cu integrare Firebase pentru autentificare, stocare date și hosting.

Platforma este concepută pentru a fi utilizată în context educațional de către elevii claselor I–IV din cadrul **Școlii Primare „Alexandru Donici” (mun. Cahul)**, ca instrument interactiv de formare a competențelor de utilizare sigură și responsabilă a internetului, prin module, scenarii și jocuri educaționale.

Platforma va include:

- 4 module educaționale (Clasa I–IV)
- 16 scenarii interactive (4 per clasă)
- 8 jocuri educaționale (2 per clasă)
- 4 teste de evaluare (10 întrebări/test)
- Sistem de autentificare și salvare progres în Firebase

---

## 2. Beneficiarul educațional (instituția vizată)

**Școala Primară „Alexandru Donici”, mun. Cahul** este instituția vizată ca beneficiar educațional al proiectului. SafeNet Junior este dezvoltată ca o platformă web cu utilizare practică, care poate fi integrată în activități didactice și extracurriculare (ex. Educație Digitală, activități tematice, laboratoare), în funcție de oportunitățile și deciziile instituției.

Mențiune: platforma este dezvoltată în cadrul competiției TJA și are caracter educațional; nu colectează date personale sensibile ale elevilor.

---

## 3. Tehnologii utilizate

Frontend:
- HTML5
- SCSS (compilat în CSS)
- Tailwind CSS (CLI)
- JavaScript (ES6)

Backend / Servicii:
- Firebase Authentication
- Firestore Database
- Firebase Hosting
