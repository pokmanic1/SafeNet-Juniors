Documentația - Răspunde Corect

Nivelul 1 - Începător

Bazele Siguranței

1. Parola: Este o cheie secretă pentru conturi. Ea trebuie păstrată secretă (nu se spune prietenilor).

2. Parole Slabe: Evită parolele simple ca "1234". O parolă bună are litere și simboluri.

3. Date Personale: Reprezintă informații despre o persoană (nume, adresă, telefon).

4. Ajutor: Dacă vezi ceva ciudat pe net, spune imediat unui adult!

5. Internetul: Este o rețea uriașă de calculatoare conectate între ele.

6. Comunicare: Este sigur să vorbești online doar cu persoane cunoscute în realitate.

7. Calculatoare Publice: Deconectează-te mereu din cont după ce ai terminat utilizarea.

8. Securitate: Simbolul "Lacăt" în browser arată că un site este sigur.

Nivelul 2 - Intermediar

Cunoștințe Medii

1. Regula Parolei: O parolă sigură are minimum 8 caractere și conține litere și cifre.

2. Mesaje Nedorite: Spamul reprezintă mesaje nesolicitate. Mesajele suspecte se ignoră.

3. Protecție: Antivirusul este programul care protejează calculatorul de viruși.

4. Descărcări: Verifică cu un adult înainte de a descărca orice aplicație.

5. Cont Online: Reprezintă profilul tău personal pe un site sau o aplicație.

6. Phishing: O metodă de fraudă prin care cineva încearcă să îți fure datele prin mesaje false.

7. Responsabilitate: Înseamnă să respecți mereu regulile de siguranță online.

8. Alerta: Un mesaj de avertizare despre o posibilă problemă de securitate.

Nivelul 3 - Avansat

Securitate Pro

1. Cyberbullying: Reprezintă hărțuirea sau comportamentul agresiv pe internet.

2. Criptarea: Metoda de a ascunde informațiile într-un cod pentru a fi secrete.

3. Firewall: Un sistem/program care blochează accesul periculos în rețea.

4. Hacker: Persoană care încearcă să intre în sisteme fără permisiune.

5. Adresa IP: Un număr unic care identifică un dispozitiv pe internet.

6. VPN: Creează o conexiune securizată și privată pe internet.

7. Cloud & Backup: Cloud-ul stochează date pe net; Backup-ul este copia de siguranță a datelor.

8. Identitatea Digitală: Toate informațiile despre tine care există pe internet.

Nivelul 4 - Expert

Securitate Cibernetică

1. Protocoale: HTTPS indică o conexiune web securizată (spre deosebire de HTTP).

2. Proxy: Server care trimite cereri către internet în locul utilizatorului.

3. DNS: Sistemul care traduce numele site-urilor (google.com) în adrese IP.

4. Sisteme: macOS este sistemul de operare dezvoltat de Apple.

5. DuckDuckGo: Un motor de căutare axat pe protejarea confidențialității.

6. Tor Project: O rețea specială creată pentru navigare complet anonimă.

7. Monitorizare: Procesul de observare a activității sistemelor pentru siguranță.

Sfat: Folosește mereu parole puternice pentru a proteja orice cont!
