Documentația - Creează Parola

Ce este o parolă puternică?

O parolă puternică este o combinație de caractere greu de ghicit de către altcineva sau de către un calculator. Ea protejează conturile tale online împotriva accesului neautorizat.

Regulile de bază

  • ✓ Minim 12 caractere lungime
  • ✓ Cel puțin o literă mare (A, B, C…)
  • ✓ Cel puțin o literă mică (a, b, c…)
  • ✓ Cel puțin o cifră (0–9)
  • ✓ Cel puțin un simbol special (!, @, #, $, %, &…)

Ce să eviți

  • ✗ Numele tău sau al rudelor
  • ✗ Data ta de naștere (ex: 01012010)
  • ✗ Parole simple precum 123456 sau parola
  • ✗ Același cuvânt repetat: abcabc
  • ✗ Informații personale publice (echipa favorită, orașul)

Parolă slabă vs. Parolă puternică

❌ Parolă slabă

  • ana2005
  • 123456
  • fotbal
  • parola1

✅ Parolă puternică

  • Ana@2005!Bun
  • X7#mLoP2@kR!
  • Fotbal$22!Safe
  • P@r0La#Buna99

Tehnica Passphrase

O metodă ușor de reținut este să combini mai multe cuvinte aleatorii separate prin simboluri:

Mere-Roșii-Cer-42!

Ușor de reținut, greu de ghicit ✓

O parolă diferită pentru fiecare cont

Dacă folosești aceeași parolă peste tot și un site este spart, toate conturile tale devin vulnerabile. Folosește parole unice pentru fiecare cont important: email, rețele sociale, școală.

Nu îți împărtăși parola

Parola este secretul tău. Nu o spune nimănui — nici prietenilor, nici colegilor. Niciun site sau serviciu legitim nu îți va cere vreodată parola prin mesaj sau email.

Managere de parole

Un manager de parole este o aplicație care ține minte toate parolele tale în mod securizat. Tu trebuie să reții doar o singură parolă principală. Exemple populare: Bitwarden, 1Password, KeePass.

Autentificarea în doi pași (2FA)

Pe lângă parolă, activează autentificarea în doi pași acolo unde este disponibil. Aceasta adaugă un al doilea nivel de protecție — de obicei un cod trimis pe telefon — astfel încât chiar dacă cineva îți află parola, nu poate accesa contul.
